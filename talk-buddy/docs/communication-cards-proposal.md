# Communication cards — proposal only

No new categories or expanded card set are implemented in this iteration.

I recommend keeping four essentials visible in the same positions: **Help**, **No / stop**, **Break**, and **Repeat**. Below them, offer text-labeled tabs for **Needs & support**, **Boundaries**, **Questions**, **Feelings**, and **Everyday talk**, with an optional Favorites view. Start with a modest curated set, then expand using learner feedback rather than showing a large wall of phrases.

This adapts a core/fringe organization: frequently useful communication stays close at hand, while less frequent or situation-specific language has a consistent home. AssistiveWare's AAC guidance describes this separation and its boards combine core and fringe vocabulary:

- https://www.assistiveware.com/learn-aac/learn-about-core-word-teaching-strategies
- https://www.assistiveware.com/learn-aac/quick-communication-boards

For TalkBuddy, keep the wording age-neutral, the positions predictable, the cards large and keyboard accessible, and the selected phrase editable before Send. Color can help distinguish groups but should always be accompanied by a text label. Pictures can remain optional. Avoid automatic AI reordering, which would make familiar phrases harder to find.

This is a proposed phrase-bank design for conversation practice, not an implementation of a full AAC vocabulary system.
